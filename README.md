# Prism — セットアップ手順

iPhoneで自分のmp3を聴くための個人用プレイヤーです。費用は一切かかりません。
**コードを書く必要はありません。** 以下の順に進めてください。

---

## 全体の流れ

```
① 公開URLを作る（GitHub Pagesを有効にする）
        ↓
② iPhoneのSafariで開いてホーム画面に追加
        ↓
③ PCのmp3をiPhoneに持っていく
        ↓
④ アプリの「＋」から曲を取り込む → 完成
```

ファイルはすでに GitHub に置いてあります（https://github.com/kou56250046-cloud/music-app）。
①から始めてください。

---

## ① 公開URLを作る

1. https://github.com/kou56250046-cloud/music-app/settings/pages を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜3分待ってページを再読み込みすると、上部にURLが表示される

```
https://kou56250046-cloud.github.io/music-app/
```

> ※リポジトリをPublicにしているのは、無料でWeb公開するための条件です。公開されるのは**アプリのプログラムだけ**で、あなたの音楽ファイルは一切アップロードされません。曲はiPhoneの中だけに保存されます。

---

## ② iPhoneのホーム画面に追加する

> **重要**: 必ず **Safari** で開いてください。ChromeやLINE内のブラウザではホーム画面に追加できません。

1. iPhoneのSafariで①のURLを開く
2. 画面下の **共有ボタン**（四角に上矢印）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップ
4. **「追加」** をタップ

ホーム画面にアイコンができます。**以降はこのアイコンから起動してください。**
（Safariのタブから開くのと、アイコンから開くのは別物として扱われます）

---

## ③ PCのmp3をiPhoneに持っていく

アプリに取り込む前に、mp3をiPhoneから見える場所に置く必要があります。無料でできる方法を3つ挙げます。

| 方法 | 手順 | 向き不向き |
|---|---|---|
| **iCloud Drive**（おすすめ） | PCに「iCloud for Windows」を入れ、iCloud Driveのフォルダにmp3をコピー。iPhoneの「ファイル」アプリに現れる | 無料5GB。500MBなら余裕 |
| Googleドライブ | PCからアップロード → iPhoneのGoogleドライブアプリでダウンロード | 無料15GB |
| ケーブル直結 | iPhoneをPCに繋ぎ、エクスプローラーから「ファイル」アプリの領域にコピー | ソフト不要だが手順がやや面倒 |

> **PCで取り込んだ曲はiPhoneには出てきません。** ブラウザの保存領域は端末ごとに完全に分かれているためです。取り込み作業は必ずiPhone側で行ってください。

---

## ④ 曲を取り込む

1. ホーム画面のPrismアイコンから起動
2. 右上の **＋** をタップ
3. ファイル選択画面で、③で置いた**mp3を複数まとめて選択**
4. 取り込みが終わるまで待つ（時間がかかる場合は「中止する」で止められます）

曲名は「アーティスト名 - 曲名.mp3」という形式のファイル名から自動で判別します。
違っていたら、曲の右の **⋮** →「曲名・アーティストを編集」で直せます。

---

## 使い方

| やりたいこと | 操作 |
|---|---|
| 曲を再生 | 一覧の曲をタップ |
| 全画面プレイヤーを開く | 下部の再生バーをタップ |
| リピートを切り替え | プレイヤー右下のループアイコン（なし → リスト全体 → 1曲） |
| シャッフル | プレイヤー左下のアイコン。緑に光れば有効 |
| 次に何が流れるか見る | プレイヤーの曲名の下に表示されます |
| プレイリストを作る | 「プレイリスト」タブ →「＋ 新しいプレイリスト」 |
| 曲をプレイリストに入れる | 曲の **⋮** →「プレイリストに追加」 |
| プレイリストから一覧に戻る | 左上の戻るボタン、または画面の左端から右へスワイプ |
| 曲を探す | ライブラリ上部の検索欄 |
| 残り容量を見る | 「設定」タブ |
| 消してしまった曲を戻す | 削除直後に出る「元に戻す」をタップ（数秒で消えます） |

検索で1曲に絞ってから再生しても、そのあとはライブラリの続きが流れます。

## ⑤ 動作チェック（ここが今回いちばん大事です）

作った直後に、以下を必ず確認して結果を教えてください。
**これが要件定義書のPhase 0（技術検証）にあたります。**

### チェック1：オフラインで聴けるか
- [ ] 曲を数曲入れる
- [ ] iPhoneを**機内モード**にする
- [ ] ホーム画面のアイコンからPrismを起動
- [ ] 曲が普通に再生できる

→ できなければ、Service Workerが効いていません。

### チェック2：バックグラウンド再生ができるか ★最重要
- [ ] 曲を再生する
- [ ] **電源ボタンを押して画面を消す**
- [ ] 音が鳴り続けるか？
- [ ] ロック画面に曲名・ジャケット・再生ボタンが出るか？
- [ ] **ロック画面のシークバーが動くか？**（曲の途中まで進むか）
- [ ] ホームに戻って他のアプリを開いても鳴り続けるか？

→ **ここで音が止まる場合、PWAではこの機能を実現できません。** その時点で方式変更を検討します。

### チェック3：どれだけ入るか
- [ ] 手持ちのmp3を**全部**取り込んでみる
- [ ] 「設定」タブの「保存容量」を見る
- [ ] 途中で止まった場合、**設定画面に「保存の上限に達した記録」が残ります**。その数字を教えてください（メモは不要です）

### チェック4：データが消えないか
- [ ] 上記が終わったら**1週間ふつうに使う**
- [ ] 数日空けて開いたときに曲が残っているか確認

設定画面の「データの自動削除よけ」は、iPhoneでは**「この端末では不可」**と表示されます。
これはiOSの制約で、対策はホーム画面のアイコンから定期的に開くことだけです。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「ホーム画面に追加」が出ない | Safariで開いているか確認（Chrome不可） |
| 白い画面のまま | URLの末尾に `/` があるか確認。それでもだめならSafariのタブを全部閉じて開き直す |
| 曲が再生されない | mp3以外の形式（m4a等）の可能性。設定タブの「動作チェック」も確認 |
| 取り込みが途中で止まる | 容量上限の可能性。設定画面に記録が残ります |
| 更新したのに変わらない | アプリを一度閉じて開き直す。「新しいバージョンがあります」と出たらタップ |

アプリは起動を速くするため、いったん保存した内容から先に表示します。
そのため更新直後は前の状態が出ることがありますが、開き直せば反映されます。

---

## データについて

- 音楽ファイルは**iPhoneの中だけ**に保存されます。どこにも送信されません。
- アプリは外部のサーバーに一切アクセスしません（文字のデザインもアプリに同梱しています）。そのため機内モードでも起動します。
- 「設定」→「プレイリスト構成を書き出す」で、プレイリストの構成をJSONファイルとして保存できます。万一データが消えたとき、曲を入れ直したあとに「読み込む」で復元できます（曲そのもののバックアップではありません）。
